## Format Catatan Feedback

Setiap kali mendapat feedback, catat ke file terpisah di folder `feedback/` dengan format:

```markdown
# Feedback — [Nama User] — [Tanggal]

## Identitas
- Nama: [nama]
- Posisi: [posisi]
- Channel: [whatsapp / form / interview / observasi]

## Poin Feedback

### Positif
1. [poin positif]

### Keluhan / Kendala
1. [poin kendala]

### Permintaan Fitur
1. [request fitur]

## Prioritas (Tim Dev)
- [ ] Segera (mendesak, menghambat kerja)
- [ ] Penting (akan sangat membantu)
- [ ] Nice to have (boleh nanti)

## Tindak Lanjut
- [ ] Sudah dijawab
- [ ] Masuk backlog
- [ ] Butuh diskusi lanjutan
```

## Cara Memproses Feedback

1. Kumpulkan semua feedback di folder `feedback/`
2. Setiap 2 minggu, review dan kelompokkan: bug vs request vs improvement
3. Tentukan prioritas berdasarkan:
   - **Frekuensi**: berapa banyak user mengalami masalah yang sama
   - **Dampak**: seberapa parah masalahnya (kehilangan data > kosmetik)
   - **Usaha**: estimasi effort development
4. Masukkan ke backlog development
5. Konfirmasi ke user yang memberi feedback: "Masukan Bapak/Ibu sudah kami tindak lanjuti di versi berikutnya"
